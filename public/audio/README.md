# Ambient + guided meditation audio (ZenU 2.1)

- `fire.wav`, `rain.wav`, `forest.wav`, `ocean.wav` — ambient loops for `ZenSoundscapeBar`
- `meditation/*.wav` — soft guided beds used when DB `audio_url` is null

Replace these placeholders with production narration MP3s when available.
Optionally set `app.meditations.audio_url` to the public path or a CDN URL (no schema change).
